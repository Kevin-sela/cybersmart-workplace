# CyberSmart Workplace

A planned low-bandwidth e-learning application for a short course on **Cybersecurity Awareness for Working Professionals**.

## Repository layout
- `backend/` — API, persistence, authentication and assessment services.
- `frontend/` — learner-facing course interface.
- `docs/PRD.md` — product requirements and scope.
- `docs/DESIGN.md` — UX and visual design principles.
- `docs/ARCHITECTURE.md` — system structure and key flows.
- `AGENTS.md` — working rules for AI coding agents and contributors.
- `report/` — IT 404 report draft for Tasks A and B.

## Status
Planning scaffold only. No working backend, frontend, LMS integration, or deployed prototype has been implemented yet.
